## Claims audit

README and portfolio figures resolve to M1–M7 verification files or raw results. The release does
not claim SOTA, best-known-solution gaps, strict one-second compliance, statistical significance,
or longer-budget generalization. It prominently retains the 208/660 solver-call overruns, the zero
timely held-out ALNS/Restricted pairs, and the inconclusive no-restart ablation.

## Publication handoff

The assistant creates the release commit and annotated tag locally but does not push. The user
publishes both refs with:

```bash
git push origin main
git push origin v1.0.0
```

GitHub release text can use `docs/release_notes_v1.0.0.md` verbatim or link it from a shorter
summary. The optional demo recording follows `docs/demo_video_zh.md`; no generated video binary is
stored in the repository.
