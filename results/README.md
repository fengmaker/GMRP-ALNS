# Results

Generated experiment runs belong in `results/runs/` and reports in `results/report/`; both are
ignored until a result-freezing policy is defined. Published aggregate results must remain
traceable to raw run records, configuration, seed, time limit, dependency versions, hardware,
and Git commit. No preregistered solution-quality benchmark has been run yet. The M3
incremental-state microbenchmark and M4 one-second A-set acceptance run are documented separately
in `docs/m2_m3_verification.md` and `docs/m4_verification.md`; neither is a competitive benchmark.
